IA conversacional

Profon

Assistente de planejamento de aulas que conversa com o professor pelo Telegram.

  • Toda manhã envia as turmas do dia, o roteiro da aula e um questionário para o quadro, gerados por IA e alinhados à BNCC.
  • Lê o PDF da BNCC e extrai as 391 habilidades de Língua Portuguesa que fundamentam o conteúdo.
  • Funciona com dois provedores de IA (Claude e Gemini): respeita o limite de requisições, usa um modelo reserva e recebe respostas em JSON validado.
  • Quando uma aula é cancelada, a agenda se recalcula sozinha. O envio da manhã não depende da IA.

Em uso por professores

BOT PEGE

Robô que automatiza o lançamento de diários e planejamentos no sistema Professor Online da rede municipal.

  • Uso esse robô nas minhas turmas, e colegas professores também usam para lançar as próprias aulas.
  • Lê as aulas de planilhas Excel, abre o Chrome com Selenium, faz login e lança cada aula, pulando as que já existem.
  • Tem modo simulação e, no fim, um relatório com o que foi lançado, pulado ou deu erro, com log e captura de tela de cada falha.
  • Interface gráfica em Tkinter, com cadastro de vários professores.
  • Python
  • Selenium
  • Tkinter
  • openpyxl
  • unittest · 30 testes

Com encomenda de cliente

PedeAí

Sistema de gestão para restaurantes, lanchonetes e açaiterias.

  • Pedidos, mesas, PDV, cozinha (KDS), caixa, divisão de conta, desconto e transferência entre mesas.
  • Versão atual: aplicativo Windows que funciona sem internet, em C#/.NET 10, com 288 testes, permissões por perfil verificadas no servidor local, auditoria e backup criptografado (AES-256-GCM).
  • Versão anterior: web, com API REST em Python (FastAPI) e front-end em React. As telas ao lado são dessa versão.

Cabo Pro

Plataforma web para organizar a base de apoio de campanhas eleitorais.

  • Cabos eleitorais cadastram eleitores pelo celular, com link exclusivo e PIN. A coordenação acompanha metas e relatórios em tempo real.

Como eu trabalho com IA

Eu dirijo, a IA acelera. O problema, as regras de negócio, a arquitetura e a validação ficam comigo.

IA dentro do produto

No Profon, integro as APIs do Gemini e do Claude para gerar roteiros e questionários em JSON estruturado e validado. O código respeita o limite de requisições e troca de modelo quando o principal falha. Os prompts são escritos em português por quem estudou a língua.

Agentes de código como ferramenta

Uso Claude Code e Codex para implementar, revisar e escrever testes mais rápido. Antes de pedir código, escrevo a especificação. Depois, confiro tudo com testes automatizados: são mais de 440 nos projetos.

Google Cloud e deploy

Publiquei a versão web do PedeAí no Firebase Hosting (Google Cloud) e desenhei a arquitetura da API com Cloud Run e Cloud SQL. Também publico projetos na Vercel e no GitHub Pages.

Vídeo gerado por código

Criei o vídeo de apresentação do PedeAí com Remotion, em que o vídeo é escrito em React, e com narração em voz neural (TTS) gerada por script em Python.
